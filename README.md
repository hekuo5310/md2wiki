# MD2Wiki

一个纯前端的单文件工具，把 Markdown 实时转换为 MediaWiki 维基文本（Wikitext）。无需安装、无需联网，用浏览器打开即可使用。

---

## 功能特性

### 行内格式
- **加粗**、*斜体*、***粗斜体***
- ~~删除线~~ → `<s>`
- ==高亮== → `<mark>`
- 上标 `^x^` → `<sup>`，下标 `~x~` → `<sub>`
- `` `行内代码` `` → `<code>`
- 链接 `[文字](url)` → `[url 文字]`
- 图片 `![alt](url)` → `[[File:url|alt]]`（外链图片降级为普通外链）
- 自动链接 `<https://...>` → 直接输出 URL
- 脚注引用 `[^id]` → `<ref name="id">…</ref>`
- Emoji 短代码 `:smile:` → 😄
- 行内数学 `$...$` → `<math>...</math>`

### 块级格式
- ATX 标题 `# ~ ######` → `= 标题 =`
- Setext 标题（下划线 `===` / `---`）→ `= 标题 =`
- 标题锚点 `{#custom-id}` → `<span id="custom-id"></span>`
- 水平线 `---` / `***` / `___` → `----`
- 表格（支持左/中/右对齐）→ `{| class="wikitable" … |}`
- 围栏代码块 ` ```lang ` → `<syntaxhighlight lang="lang">`（可切换为 `<pre>`）
- 引用块 `>` → `<blockquote>`
- 有序 / 无序列表，支持嵌套 → `#` / `*`
- 任务列表 `- [x]` / `- [ ]` → `☑` / `☐`
- 定义列表 `术语` + `: 定义` → `; 术语` / `: 定义`
- 数学公式块 `$$...$$` → `<math display="block">`
- 注释 `[//]: # (内容)` → `<!-- 内容 -->`
- 目录 `[TOC]` → `__TOC__`

### 脚注自动处理
- 提取所有 `[^id]: 内容` 定义行，从正文移除
- 正文中的 `[^id]` 转为 `<ref>`
- 若页面使用了脚注，自动在末尾追加 `<references/>`

### 语法变通（HTML 标签适配）
- `<img src="..." width="..." alt="...">` → `[[File:...|100px|alt]]`（本地图片）
- `<a href="..." target="_blank">文字</a>` → `[url 文字]`
- `<font color="red">` → `<span style="color:red">`
- `<p style="..." align="...">` → `<div style="...">`
- `<ins>` / `<u>` / `<del>` / `<mark>` / `<kbd>` 原样保留（维基原生支持）

### 界面
- 左右分栏：左侧 Markdown 输入，右侧维基文本实时输出
- 顶部工具栏可开关各项转换功能
- 实时统计行数与字符数
- 一键复制输出、下载为 `.wiki` 文件
- Tab 键插入两个空格，方便缩进
- 深色主题，响应式布局

## 快速开始

1. 下载 `index.html`
2. 用现代浏览器（Chrome / Edge / Firefox / Safari）打开
3. 在左侧粘贴或输入 Markdown
4. 右侧即时显示转换后的维基文本
5. 点击「复制」或「下载 .wiki」获取结果

无需服务器、无需构建、无第三方依赖。

## 工具栏选项

| 选项 | 默认 | 说明 |
|---|---|---|
| Emoji 短代码 | 开启 | 把 `:smile:` 等替换为 Unicode Emoji |
| 脚注 → `<ref>` | 开启 | 提取脚注定义并转换为 `<ref>` 标签 |
| 代码块高亮 | 开启 | 代码块输出 `<syntaxhighlight>`，关闭则输出 `<pre>` |
| 任务列表 ☑/☐ | 开启 | `- [x]` / `- [ ]` 转为 `☑` / `☐` |
| 数学公式 → `<math>` | 开启 | `$...$` 与 `$$...$$` 转为 `<math>` |
| 表格 class | `wikitable` | 表格输出的 CSS class |

| Markdown | 维基文本 |
|---|---|
| `# 标题` | `= 标题 =` |
| `**粗体**` | `'''粗体'''` |
| `*斜体*` | `''斜体''` |
| `~~删除~~` | `<s>删除</s>` |
| `==高亮==` | `<mark>高亮</mark>` |
| `[文字](url)` | `[url 文字]` |
| `![alt](img.png)` | `[[File:img.png\|alt]]` |
| `` `code` `` | `<code>code</code>` |
| `- [x] 任务` | `* ☑ 任务` |
| `> 引用` | `<blockquote>引用</blockquote>` |
| `[^1]` + `[^1]: 注` | `<ref name="1">注</ref>` + 末尾 `<references/>` |
| `:smile:` | 😄 |
| `$x^2$` | `<math>x^2</math>` |

## 实现说明

- 纯 JavaScript，单文件，无外部依赖
- 行内解析使用保护机制：先提取行内代码，避免其中的 `*`、`_` 等被误解析
- 块级解析逐行扫描，支持嵌套引用与列表
- 脚注定义在预处理阶段提取，正文中按首次出现顺序生成 `<ref>`，重复引用使用 `<ref name="..."/>`
- 输出使用 `<textarea readonly>`，复制优先走 `navigator.clipboard`，非安全上下文回退到 `execCommand('copy')`

## 已知限制

- **Emoji 短代码**仅内置常用子集，未覆盖完整 GitHub Emoji 列表，可按需扩充
- **脚注续行**仅支持 4 空格或 Tab 缩进的简单续行，复杂多段脚注可能需要手动调整
- **数学公式**直接原样包裹为 `<math>`，不校验或转换 LaTeX 语法
- **任务列表**使用 Unicode `☑` / `☐`，不是维基模板，如需模板可自行修改
- **HTML 变通**只适配了常见标签，维基对 `style`、`target` 等属性支持有限，可能被过滤
- **外链图片**不会转为 `[[File:...]]`，因为维基不支持外链图片，会保留为普通链接
- **表格**不支持单元格内换行、单元格内块级元素等复杂情况
- **浏览器兼容性**：使用了正则 lookbehind（`(?<!...)`），需要现代浏览器（Chrome 62+、Firefox 78+、Safari 16.4+）

## 自定义扩展

### 扩充 Emoji 短代码
在脚本开头的 `EMOJI` 对象中添加键值对：

```js
const EMOJI = {
  smile: '😄',
  // 新增：
  my_custom_emoji: '🎯'
};
```

### 修改表格默认 class
在工具栏输入框中修改，或直接改 HTML 中 `value="wikitable"`。

### 添加新的转换规则
- 行内规则：在 `inline()` 函数中按顺序添加 `text = text.replace(...)`
- 块级规则：在 `convertBlocks()` 的 `while` 循环中添加分支
